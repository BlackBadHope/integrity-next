# Roadmap

Integrity Guardian `6.0.0` is the first stable public source release.

## Stable release guarantees

- reproducible install from a clean clone;
- Linux and Windows package acceptance;
- stable public CLI and descriptor contract;
- complete public documentation links;
- no private or customer data in the public projection;
- resolved release-blocking security reports.

## Next milestones

1. **Portable adapters** — documented capability discovery without embedded
   credentials or production authority.
2. **Independent observer tooling** — simpler verification and replay reports.
3. **Packaging** — evaluated PyPI publication and reproducible release assets.

Milestone status is evidence-based. A green synthetic suite does not claim a
production deployment or operational acceptance.
