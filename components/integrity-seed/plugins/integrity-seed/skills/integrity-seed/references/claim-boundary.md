# Claim boundary

- A source hash identifies exact bytes; it is not a security audit or deployment.
- A signed startup receipt binds this service's PID, nonce, source, workspace,
  process start and executable. It is not target-action authorization.
- A healthy loopback endpoint proves local service readiness at that observation.
  It does not prove context was delivered to a particular model or remote host.
- A selected event proves source-linked selection, not execution of its old task.
- Missing selected context is reported explicitly; an empty result does not prove
  canonical memory is empty. Keep unavailable and degraded states visible.
- Closure claims require evidence appropriate to their scope. Report partial,
  failed and unverified checks accurately and keep historical records append-only.
- Token authentication and workspace custody remain required; do not substitute
  a known PID, borrowed state directory, alternate host or unsigned receipt.
